## What's included

Every cloud browser session runs in a hardened Chromium fork with stealth enabled by default — no configuration needed.

- **Anti-detect browser fingerprinting** — Canvas, WebGL, fonts, navigator, and
  other browser fingerprints are varied per session to reduce detectable
  automation signatures.
- **Ad and cookie banner blocking** — Banners are dismissed automatically so the agent sees clean pages and executes faster.
- **Anti-bot resilience** — Hardened browser fingerprints and proxy routing can
  reduce automated traffic blocks. Site behavior varies, so access is not
  guaranteed.

Cloud browsers also solve reCAPTCHA and other supported challenges automatically.
See [CAPTCHA handling](/cloud/browser/captcha-handling) for what to do when a
solver is still working or a site has a specific anti-bot issue.
