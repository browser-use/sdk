Every cloud browser runs in a **hardened Chromium fork** built to look like a real user: Canvas, WebGL, font, and navigator fingerprints are randomized per session, ad and cookie banners are dismissed automatically, and CAPTCHAs are solved for you. Nothing to configure — it's on by default for agent runs and browsers you drive yourself. In [the hardest public stealth benchmark](https://browser-use.com/posts/stealth-benchmark), Browser Use passes **81%** of protected sites — the highest score of any cloud browser tested.

Requests route through **residential proxies in 195+ countries**, US by default, so traffic originates from real-user IPs in the geography you choose. Bring your own proxy if you have one.
