`browser-use-sdk/ai-sdk` exports `browserUse()`, a [Vercel AI SDK](https://ai-sdk.dev) tool. When the model calls it, Browser Use runs the task in a cloud browser and returns the agent's final answer to the model. It works with `generateText`, `streamText`, and `ToolLoopAgent` in AI SDK 6 and 7.

## Setup

```bash
npm install browser-use-sdk ai
```

Set `BROWSER_USE_API_KEY`. Get a key at [cloud.browser-use.com](https://cloud.browser-use.com/settings?tab=api-keys&new=1), or install the [Vercel Marketplace integration](/cloud/tutorials/integrations/vercel), which adds the variable to your Vercel project.

## Use the tool

```typescript
import { generateText, isStepCount } from "ai";
import { browserUse } from "browser-use-sdk/ai-sdk";

const { text } = await generateText({
  model: "openai/gpt-5.6-luna",
  tools: { browserUse: browserUse() },
  stopWhen: isStepCount(5),
  prompt: "Open https://news.ycombinator.com and summarize the top 3 stories.",
});

console.log(text);
```

In AI SDK 6, import `stepCountIs` instead of `isStepCount`.

The model sends a `task` in plain language. The tool returns:

```json
{
  "runId": "…",
  "sessionId": "…",
  "status": "completed",
  "result": "1. …",
  "error": null
}
```

A failed or cancelled run comes back with `status` and `error` set, so the model can retry or explain the failure. To keep working in the same browser, with its open pages and logins, the model passes the `sessionId` from an earlier result.

## Next.js route

Browser tasks take seconds to minutes. Set the route's `maxDuration` above the tool's `waitTimeout`.

```typescript app/api/chat/route.ts
import { convertToModelMessages, isStepCount, streamText, type UIMessage } from "ai";
import { browserUse } from "browser-use-sdk/ai-sdk";

export const maxDuration = 300;

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: "openai/gpt-5.6-luna",
    messages: await convertToModelMessages(messages),
    tools: { browserUse: browserUse({ waitTimeout: 240_000 }) },
    stopWhen: isStepCount(5),
    abortSignal: req.signal,
  });

  return result.toUIMessageStreamResponse();
}
```

## Options

| Option | Default | What it does |
| --- | --- | --- |
| `apiKey` | `BROWSER_USE_API_KEY` | API key for the V4 client. |
| `client` | new client | Reuse an existing `BrowserUse` client from `browser-use-sdk/v4`. |
| `runOptions` | none | Extra [V4 run fields](/cloud/api-v4/runs/create-run) sent with every call, such as `model`, `maxCostUsd`, `browserSettings`, or `outputSchema`. |
| `waitTimeout` | `300000` | Milliseconds one tool call waits for its run. |
| `pollInterval` | `2000` | Milliseconds between status polls. |
| `description` | built-in | The tool description the model sees. |

```typescript
browserUse({
  runOptions: { maxCostUsd: 0.5, browserSettings: { proxyCountryCode: "de" } },
  waitTimeout: 120_000,
});
```

## Cancellation and cost

The tool owns each run it starts. If `waitTimeout` passes, or the AI SDK call is aborted (for example `req.signal` when the user closes the page), the tool cancels the run and throws, and the AI SDK reports a tool error to the model. Use `maxCostUsd` in `runOptions` to cap spend per call. See [Billing](/cloud/guides/billing) for rates.
