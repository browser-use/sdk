---
title: "Stripe Link"
description: "Let a V4 agent run pay with one-time cards from your Link wallet. You approve every purchase in the Link app."
---

[Link](https://link.com) is Stripe's wallet. Connect it to your Browser Use project and a run can buy things for you: each purchase gets a one-time card, your real card is never shared with the agent, and nothing is charged until you approve it in the Link app.

<Note>
  If the Integrations page in the Cloud dashboard does not show **Link**, it is not available for your project yet.
</Note>

<Warning>
  Never approve a purchase in the Link app that you did not expect.
</Warning>

## Connect Link

<Steps>
  <Step title="Open Integrations">
    In the [Cloud dashboard](https://cloud.browser-use.com/integrations), find **Link** on the Integrations page and click **Connect**.
  </Step>
  <Step title="Sign in to Link">
    Sign in to Link in the popup and approve access. The card shows your Link email once the connection is active.
  </Step>
</Steps>

Connecting only happens in the dashboard; the API can read the connection but not create it. Click **Remove** on the same card to disconnect. Runs that hold the connection lose it on their next payment call.

## Get the connection id

```bash
curl https://api.browser-use.com/api/v4/stripe-link \
  -H "X-Browser-Use-API-Key: $BROWSER_USE_API_KEY"
```

```json
{
  "isConnected": true,
  "connectionId": "6f2c0a1e-...",
  "linkEmail": "you@example.com",
  "mode": "live"
}
```

`isConnected` is `false` with no `connectionId` when the project has no active connection or Stripe Link is unavailable. `mode` is `test` or `live`; test mode issues Stripe test cards that cannot buy anything real. See the [API reference](/cloud/api-v4/wallets/get-stripe-link-status).

## Let a run pay

Payment is opt-in per run. Pass the id as `stripeLinkConnectionId` when you create the run:

<CodeGroup>
```python Python
import os
from browser_use_sdk.v4 import BrowserUse

connection_id = os.environ["CONNECTION_ID"]  # from GET /stripe-link

with BrowserUse() as client:
    run = client.runs.create(
        "Buy a 12oz bag of whole-bean coffee from example-shop.com",
        # Not a typed SDK parameter yet; extra keyword arguments are sent as-is in the request body.
        stripeLinkConnectionId=connection_id,
    )
```
```bash curl
curl https://api.browser-use.com/api/v4/runs \
  -H "X-Browser-Use-API-Key: $BROWSER_USE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"task":"Buy a 12oz bag of whole-bean coffee from example-shop.com","stripeLinkConnectionId":"'"$CONNECTION_ID"'"}'
```
</CodeGroup>

The API returns `422` with `stripe link connection not found` when the id is not an active connection in your project, or Stripe Link is switched off.

At checkout the agent creates a spend request for that purchase. Link asks you to approve it in the app; once you do, the agent fills in the one-time card.

## Follow-up runs

- Messages queued to the [session](/cloud/agent/sessions) keep the grant from the previous run, as long as the connection is still active.
- Interrupts and new runs with `sessionId` do not inherit it. Pass `stripeLinkConnectionId` again to let them pay.
- Removing the connection in the dashboard stops every run from paying with it.
