A **browser** is a real Chromium instance running on our infrastructure — hardened for [stealth](/cloud/browser/stealth), behind [residential proxies](/cloud/browser/proxies), with [CAPTCHA solving](/cloud/browser/captcha) built in. Agent runs provision one automatically; or create one yourself and drive it directly with Playwright, Puppeteer, or raw CDP.
