title: Human in the loop
description: "Open the live browser, take over, then continue the same session."
icon: "hand"
---

Use a human checkpoint for approvals, authentication, payments, or review.
Get its `live_view_url` with the SDK's event-wait helper, which follows event
cursors and also returns `browser.reattached` when a follow-up reused the open
browser. Wait for the run to stop at the checkpoint before letting a person
interact:

<CodeGroup>
```python Python
from browser_use_sdk.v4 import BrowserUse

client = BrowserUse()
run = client.runs.create(
    "Open the login page and stop for human review",
    keepAlive=900,
)
ready = client.runs.wait_for_event(run.id, "browser.ready")
client.runs.wait_for_completion(run.id)
print(ready.data["live_view_url"])

input("Press Enter after finishing the human step...")
next_run = client.runs.create(
    "Continue from the current page",
    session_id=run.session_id,
)
```
```typescript TypeScript
import { BrowserUse, type RunCreateBody } from "browser-use-sdk/v4";
import * as readline from "node:readline/promises";

const client = new BrowserUse();
const run = await client.runs.create({
  task: "Open the login page and stop for human review",
  model: "gpt-5.6-luna",
  modelParams: { reasoning: { effort: "xhigh" } },
  keepAlive: 900,
} as RunCreateBody);
const ready = await client.runs.waitForEvent(run.id, "browser.ready");
await client.runs.waitForCompletion(run.id);
console.log(ready.data.live_view_url);

const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
await rl.question("Press Enter after finishing the human step...");
rl.close();
const nextRun = await client.runs.create({
  task: "Continue from the current page",
  model: "gpt-5.6-luna",
  modelParams: { reasoning: { effort: "xhigh" } },
  sessionId: run.sessionId,
});
```

The same session keeps the conversation and workspace. Without `keepAlive`,
its browser stops about 2 minutes after the run ends, and the follow-up starts
on a fresh browser without the human's page state. `keepAlive=900` keeps it
open for 15 minutes; the follow-up inherits the value, and kept time is billed.
See [Sessions](/cloud/agent/sessions#keep-the-browser-open-between-runs).
In a web app, replace the terminal prompt with an explicit Continue control.
Treat live-view URLs as credentials.
