## BU Ultrafast and BU Fast

**Browser tasks for a fraction of a cent.** BU Ultrafast: **\$0.00214 median recorded cost per URL check**, **8/8 correct on staging**. [Pricing and methodology](https://browser-use.com/pricing#task-cost-methodology).

- **BU Ultrafast** (`bu-ultrafast`): quick browser interactions.
- **BU Fast** (`bu-fast`): more reasoning at low token prices.

API V4, **early access** per project. [Request access](https://browser-use.com/ultrafast); signup credits work once enabled. EU and Bedrock-only routes are unsupported.

### Token rates

Customer rates in USD per 1 million tokens, including the service fee:

| Mode | Fresh input | Cached input | Cache write | Output |
| --- | ---: | ---: | ---: | ---: |
| BU Ultrafast | \$0.24 | \$0.024 | \$0.30 | \$1.20 |
| BU Fast | \$0.12 | \$0.012 | \$0.15 | \$0.60 |

For a call exceeding 272,000 prompt + cache-write tokens, input and cache rates are 2× and output is 1.5×.

Browser, network, and optional services add charges. See [task billing](/cloud/guides/billing#what-does-a-task-cost).

### Select a mode

```bash
curl https://api.browser-use.com/api/v4/runs \
  -H "X-Browser-Use-API-Key: $BROWSER_USE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"task":"Find the top Hacker News story","model":"bu-ultrafast"}'
```

Use `bu-fast` for more reasoning. Presets reject `modelParams`; projects without access receive 422 with a waitlist link.

Use REST while SDK types lag. These are V4 presets, separate from local `ChatBrowserUse`; omitting `model` selects neither.

Pass a provider model ID when creating a run, or omit `model` to use the API's default. Availability depends on your route and account.

Token prices are USD per 1 million tokens. Browser sessions
(\$0.02/hour) and network traffic (\$5/GB managed proxy or \$0.20/GB

the normalized `thinkingLevel` values available in V2 and V3.

## Bring your own key

BYOK is available to pay-as-you-go customers; no recurring subscription is required. After adding credits, add an Anthropic, OpenAI, or Google key under **Settings →
API Keys → Bring Your Own Key**. V4 uses it automatically for matching models;
no request flag is needed. You pay the provider directly, plus a 0.2× Browser
Use orchestration fee. Models from other providers use Browser Use-managed
keys.
