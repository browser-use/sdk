Omit `model` to use **GPT-5.6 Luna**, or pass a model ID when creating a run.
GPT-6 Luna (`gpt-6-luna`), GPT-6 Sol (`gpt-6-sol`), and Claude Opus 5.5
(`claude-opus-5-5`) are available on supported V4 routes. Compare
[current model token rates](https://browser-use.com/pricing#model-rates)
on the pricing page, which includes the Browser Use service fee.
Browser time and network traffic are charged separately; see
[full pricing](https://browser-use.com/pricing).

The default remains `gpt-5.6-luna`; selecting a newer model is opt-in.
Compare models on your own tasks before switching production traffic.
See [Thinking levels](/cloud/agent/thinking-levels) for reasoning controls
and defaults, which differ by model.

## All supported V4 model IDs

The V4 request schema accepts the following model IDs. The Cloud dashboard may
show a smaller curated set; availability can also depend on your account's
region, compliance requirements, rollout, and configured provider key. An
accepted ID does not guarantee access to every upstream provider. Experimental models are not recommended as a
production default. MiniMax M3 remains an API option even where it is absent
from the dashboard picker.

| Provider | Model IDs | BYOK provider |
| --- | --- | --- |
| Anthropic | `claude-opus-4.7`, `claude-opus-4.8`, `claude-opus-5`, `claude-opus-5-5`, `claude-fable-5`, `claude-sonnet-5` | Anthropic |
| OpenAI | `gpt-5.5`, `gpt-5.6`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`, `gpt-6-astra`, `gpt-6-sol`, `gpt-6-luna` | OpenAI |
| Google | `gemini-3-flash`, `gemini-3.1-pro`, `gemini-3.5-flash`, `gemini-3.6-flash` | Google |
| xAI | `grok-4.5`, `grok-4.6` | — |
| Z.ai | `glm-5.2`, `glm-5.3-flash` | — |
| DeepSeek | `deepseek-v4.1-flash`, `deepseek-v4-flash-vision` (experimental) | — |
| Xiaomi | `mimo-v2.6-pro`, `mimo-v2.6-flash` | — |

The legacy `gpt-5.6` alias resolves to `gpt-5.6-sol`.

See [Thinking levels](/cloud/agent/thinking-levels) for the reasoning controls
accepted by each model. Not every model accepts `modelParams`.

## Bring your own key

BYOK is available to pay-as-you-go customers; no recurring subscription is required. After adding credits, add an Anthropic, OpenAI, or Google key under **Settings →
API Keys → Bring Your Own Key**. V4 uses it automatically for matching models;
no request flag is needed. You pay the provider directly, plus a 0.2× Browser
Use orchestration fee. Models from other providers use Browser Use-managed
keys.
