## All supported V4 model IDs

The V4 request schema accepts the following model IDs. The Cloud dashboard may
show a smaller curated set; availability can also depend on your account's
rollout and configured provider key. An accepted ID does not guarantee access
to every upstream provider. Experimental models are not recommended as a
production default. MiniMax M3 remains an API option even where it is absent
from the dashboard picker.

| --- | --- | --- |
| Anthropic | `claude-opus-4.7`, `claude-opus-4.8`, `claude-opus-5`, `claude-fable-5`, `claude-sonnet-5` | Anthropic |
| OpenAI | `gpt-5.5`, `gpt-5.6`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`, `gpt-6-astra`, `gpt-6-luna` | OpenAI |

If your installed TypeScript SDK does not yet list `gpt-6-luna`, omit both
`model` and `modelParams` as below to use the API default, or use REST to select
that model explicitly. The API model catalog can advance before SDK type releases.

<CodeGroup>
```python Python
from browser_use_sdk.v4 import BrowserUse

client = BrowserUse()
run = client.runs.create(
    "Compare three project-management tools",

```
```typescript TypeScript
import { BrowserUse } from "browser-use-sdk/v4";

const client = new BrowserUse();
const run = await client.runs.create({

});
```
```bash curl

  -H "Content-Type: application/json" \
  -d '{"task":"Compare three PM tools"}'
```

## Bring your own key

BYOK is available to pay-as-you-go customers; no recurring subscription is required. After adding credits, add an Anthropic, OpenAI, or Google key under **Settings →
API Keys → Bring Your Own Key**. V4 uses it automatically for matching models;
no request flag is needed. You pay the provider directly, plus a 0.2× Browser
Use orchestration fee. Models from other providers use Browser Use-managed
keys.
