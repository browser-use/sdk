## 1. Install

Python 3.11 or newer.

<CodeGroup>
```bash uv
uv init --python 3.12 my-agent && cd my-agent
uv add 'browser-use==1.0.0'
```
```bash pip
python3 -m venv .venv && source .venv/bin/activate
pip install 'browser-use==1.0.0'
```
</CodeGroup>

Pin the exact version with `==`, never `>=`: browser-use moves fast, and a new release can break your code. Upgrade on purpose by changing the pin.

## 2. Set your API key

[Create a key](https://cloud.browser-use.com/new-api-key) in Browser Use Cloud and export it:

```bash
export BROWSER_USE_API_KEY=bu_...    # get one at https://cloud.browser-use.com/new-api-key
```

The key runs the default model, cloud browsers, web search, the CLI and the MCP server. A `.env` file in the working directory is read on import, so `BROWSER_USE_API_KEY=bu_...` there works too.

Prefer to sign in from the terminal? Run `browser-use login` (with uv: `uv run browser-use login`). It opens your browser and stores the key in `~/.config/browser-harness/auth.json` (over SSH, add `--device-code`). When `BROWSER_USE_API_KEY` is set, it wins over the stored key.

## 3. Run an agent

Save this as `agent.py`:

```python
from browser_use import Agent

result = Agent('Find the number of stars of the browser-use repo').run_sync()
print(result.final_result())
```

<CodeGroup>
```bash uv
uv run agent.py
```
```bash pip
python agent.py
```
</CodeGroup>

This runs `bu-fast` on the Browser Use gateway and drives a Browser Use Cloud browser, which stops when the run ends.

In async code, use `await agent.run()`. In a script, start it with `asyncio.run(...)`; in Jupyter, `await agent.run()` directly in a cell.

```python
import asyncio

from browser_use import Agent


async def main():
    agent = Agent('Find the top story on Hacker News')
    result = await agent.run()
    print(result.final_result())


asyncio.run(main())
```

## Local browser, your own model

```python
import asyncio

from browser_use import Agent, Browser, ChatOpenAI


async def main():
    agent = Agent(
        'Find the top story on Hacker News',
        llm=ChatOpenAI('gpt-6-luna'),  # reads OPENAI_API_KEY
        browser=Browser('chromium'),  # a fresh local Chrome with a temp profile
    )
    result = await agent.run()
    print(result.final_result())


asyncio.run(main())
```

`Browser('chromium')` uses the Chrome, Chromium or Edge you have installed. With none installed, run `browser-use install` once to download Chromium. See [Browsers](/open-source/browsers) and [Models](/open-source/models).

## What it costs

The library is free. The Browser Use model and cloud browsers bill to your Browser Use account; see [pricing](https://browser-use.com/pricing). Every run reports its model cost in `result.cost_usd`.
