## Report a browser-use problem

`browser-use feedback "what happened"` sends a report to the Browser Use team. Add `--category bug`, `docs`, `missing` or `other` (default: `bug`). In Python, use `browser_use.feedback(message, category='bug')`. These explicit reports are sent even with usage telemetry off; see [Telemetry](/open-source/telemetry#feedback).

From an agent cell, `report_issue(message, category='bug')` reports a library problem. MCP clients use `browser_feedback`. Both respect the telemetry setting and send at most three reports per run or MCP process. Use these for browser-use issues, with no credentials or personal data.

## Contribute

```bash
git clone https://github.com/browser-use/browser-use
cd browser-use
uv sync --all-extras
uv run pytest tests/ci
```

Tests, linters and conventions: [Contributing](/open-source/contributing).
