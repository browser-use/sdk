3. Get support for your enterprise with support@browser-use.com

## Contribute

```bash
git clone https://github.com/browser-use/browser-use
cd browser-use
uv sync --all-extras
uv run pytest tests/ci
```

The architecture, tests and conventions are in [AGENTS.md](https://github.com/browser-use/browser-use/blob/main/AGENTS.md).
