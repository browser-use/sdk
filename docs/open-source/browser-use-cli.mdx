The `browser-use` CLI is for coding agents. The agent pipes Python to it, and the CLI runs it against a browser with [Browser Harness](https://github.com/browser-use/browser-harness) helpers and raw CDP. It drives your Chrome by default, or a Browser Use cloud browser, or any CDP endpoint.

The CLI runs Python, not agent tasks: there is no `browser-use run "<task>"`. To run an agent from your code, use the [library](/open-source/quickstart).

## Install

```bash
uv tool install browser-use
browser-use --help
```

For one-off runs without installing, use `uvx browser-use`.

## Set up your coding agent

Paste this into Claude Code, Codex or another coding agent:

```text
Install browser-use with `uv tool install browser-use`, run `browser-use skill install` to register the skill, and connect it to my browser. If setup or connection fails, follow https://github.com/browser-use/browser-harness/blob/main/install.md.
```

`browser-use skill install` writes the skill for every supported agent: `agents`, `claude`, `codex`, `copilot`, `cursor`, `gemini`, `openclaw`, `opencode`. Use `--target NAME` for one, or `--path DIR` for a custom location. `browser-use skill show` prints it. More skills: [Agent skills](/open-source/skills).

## Run Python

```bash
browser-use <<'PY'
new_tab("https://example.com")
print(page_info())
PY
```

Helpers are pre-imported, and the daemon starts and attaches by itself. The `<<'PY'` form is for bash, zsh, Git Bash or WSL. In PowerShell, pipe a here-string:

```powershell
@'
new_tab("https://example.com")
print(page_info())
'@ | browser-use
```

## Your Chrome

By default the CLI attaches to the Chrome you have open, with its tabs, cookies and logins. The first time, Chrome asks whether to allow remote debugging: click **Allow**, or on macOS run `browser-use mac-approve`. If it can't connect:

```bash
browser-use --doctor
```

To use another browser with a DevTools endpoint, set `BU_CDP_URL` (or `BU_CDP_WS`), with a `BU_NAME` so it doesn't reuse the daemon attached to your Chrome:

```bash
BU_NAME=ci BU_CDP_URL=http://127.0.0.1:9334 browser-use <<'PY'
new_tab("https://example.com")
print(page_info())
PY
```

## Cloud browsers

Use a cloud browser on a headless machine, for parallel agents, or for stealth, proxies, CAPTCHA solving and cloud profiles. Sign in once:

```bash
browser-use login
```

Then start a named cloud browser and use the name for later calls:

```bash
browser-use <<'PY'
start_remote_daemon("work")
PY

BU_NAME=work browser-use <<'PY'
new_tab("https://example.com")
print(page_info())
PY

BU_NAME=work browser-use <<'PY'
stop_remote_daemon("work")
PY
```

Each name is its own browser, so parallel agents use different names. A cloud browser bills until it stops or times out. Once a name has run a cloud browser, it never falls back to your local Chrome; `BU_NAME=<name> browser-use --reload` resets it.

## Commands

| Command | What it does |
|---|---|
| `browser-use login` | Sign in to Browser Use Cloud. `--device-code` over SSH, `--api-key-stdin` to import a key. |
| `browser-use logout` | Remove the stored key. |
| `browser-use auth status` | Show the sign-in state. |
| `browser-use --doctor` | Check install, daemon and browser. |
| `browser-use mac-approve` | Approve Chrome's macOS remote-debugging prompt. |
| `browser-use --reload` | Restart the daemon. |
| `browser-use install` | Download Chromium for the library's `Browser('chromium')`. |
| `browser-use skill [show \| install]` | Print or install the agent skill. |
| `browser-use --cli-mcp` | Run the [MCP server](/open-source/mcp). |
| `browser-use --version` | Print the versions. |

Update with `uv tool upgrade browser-use`. The 0.x subcommands (`open`, `state`, `click`, `run`, ...) print what replaced them.
