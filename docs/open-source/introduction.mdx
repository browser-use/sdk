```python
from browser_use import Agent

result = Agent('Find the number of stars of the browser-use repo').run_sync()
print(result.final_result())
```

browser-use is an MIT-licensed Python library. You give it a task, and the agent completes it in a real browser by writing Python: [browser-harness](https://github.com/browser-use/browser-harness) helpers and raw Chrome DevTools Protocol (CDP) calls in a persistent REPL. It runs on [Pydantic AI](https://ai.pydantic.dev).

Defaults:

- **Model:** `bu-fast` on the Browser Use gateway.
- **Browser:** a Browser Use Cloud browser, stopped when the run ends.
- **Key:** one Browser Use key runs both. Create one at [cloud.browser-use.com/new-api-key](https://cloud.browser-use.com/new-api-key) and set `BROWSER_USE_API_KEY`, or run `browser-use login`.

Every default can be swapped. Use `Browser('chromium')` for a local browser, and `ChatOpenAI`, `ChatAnthropic`, `ChatGoogle` or any Pydantic AI model string for your own model.
